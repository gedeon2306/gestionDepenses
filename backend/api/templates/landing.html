Guide rapide Endpoints Exemples

Prise en main

Connectez-vous à l’API en quelques lignes de code. Toutes les réponses sont au format JSON.

Base URL

Utilisez cette base pour tous vos appels :

{{ request.scheme }}://{{ request.get_host }}/api/

Authentification

Exemple avec token Bearer (à adapter selon ton implémentation) : 

Authorization: Bearer <votre_token>

Formats de réponse

Les endpoints renvoient un JSON cohérent :

{
  "status": "success",
  "data": { ... },
  "error": null
}

Endpoints principaux

Voici les endpoints actuels de ton API.

POST /api/register/

Inscription d’un nouvel utilisateur.

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/register/" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Alice",
    "email": "alice@example.com",
    "password": "motdepasse"
  }'
POST /api/login/

Connexion et génération des tokens JWT (access + refresh).

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/login/" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alice@example.com",
    "password": "motdepasse"
  }'
POST /api/token/refresh/

Rafraîchit le token d’accès à partir du refresh token.

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/token/refresh/" \
  -H "Content-Type: application/json" \
  -d '{
    "refresh": "<refresh_token>"
  }'
GET POST
/api/transactions/

Liste toutes les transactions de l’utilisateur connecté (GET) et permet d’en créer de nouvelles (POST). 

curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/transactions/" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <access_token>"
curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/transactions/" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <access_token>" \
  -d '{
    "label": "Course",
    "amount": 42.50,
    "currency": "EUR",
    "category": "Alimentation"
  }'
GET PUT DELETE
/api/transactions/<uuid:pk>/

Récupère, modifie ou supprime une transaction spécifique appartenant à l’utilisateur connecté. 

curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/transactions/123e4567-e89b-12d3-a456-426614174000/" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <access_token>"
curl -X PUT "{{ request.scheme }}://{{ request.get_host }}/api/transactions/123e4567-e89b-12d3-a456-426614174000/" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <access_token>" \
  -d '{
    "label": "Course corrigée",
    "amount": 40.00
  }'
curl -X DELETE "{{ request.scheme }}://{{ request.get_host }}/api/transactions/123e4567-e89b-12d3-a456-426614174000/" \
  -H "Authorization: Bearer <access_token>"
GET PUT /api/profile/

Récupère les informations de l’utilisateur connecté (GET) et permet de les mettre à jour partiellement (PUT). 

curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/profile/" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <access_token>"
curl -X PUT "{{ request.scheme }}://{{ request.get_host }}/api/profile/" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <access_token>" \
  -d '{
    "name": "Nouveau Nom"
  }'

Exemples de code

Intégrez l’API dans vos projets front ou backend en quelques lignes. 

async function getTransactions() {
  const response = await fetch("{{ request.scheme }}://{{ request.get_host }}/api/transactions/", {
    headers: {
      "Accept": "application/json",
      "Authorization": "Bearer <access_token>"
    }
  });

  if (!response.ok) {
    throw new Error("Erreur API");
  }

  const data = await response.json();
  console.log(data);
}
import requests

BASE_URL = "{{ request.scheme }}://{{ request.get_host }}/api/"

def get_transactions(token):
    headers = {
        "Accept": "application/json",
        "Authorization": f"Bearer {token}",
    }
    r = requests.get(BASE_URL + "transactions/", headers=headers)
    r.raise_for_status()
    print(r.json())
